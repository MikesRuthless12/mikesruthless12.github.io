What it is

Turning a loop into MIDI, or a MIDI file into audio, usually means a chain of tools, an export, a re-import and a lot of guessing about what came out.

Flipcopy is a copy machine. Put an audio file or a MIDI file on its glass and it prints the original — the real waveform, or every note, with its data. Press the green START and it prints the copy in the other form: audio in, MIDI out; MIDI in, audio out.

The copy comes out as a printed page with a lime-green frame around its clip. Grab the frame and drag it onto a track in your DAW. Every copy is a real file that stays where it is, so your project never loses it.

See it copy

The copier, rendered in Blender: the original lands on the glass, the lid closes, the lamp sweeps, and the copy slides out onto the tray.

What is in it

The copier

A photoreal copy machine rendered in Blender. Put a clip on the glass and it prints the real thing: every note, or the real waveform, with its tempo, length and levels.

The green START

Dropping a clip only places it on the glass. Nothing is copied until you press START, so nothing happens that you did not ask for.

Audio → MIDI

The drums, bass, melody, countermelody and chords found in a loop, one page each, printed back to back from a single scan, so they drag into your DAW as separate tracks.

MIDI → audio

A MIDI file played through a real instrument, and drums through a drum machine, printed as an audio file you can drag.

Drag the copy

Every page wears a lime-green frame around its clip. Grab it and drop it on a track. The file is real, and Flipcopy never overwrites or deletes it.

The browser

A file browser with a preview player, from Freally Oscillate. It shows a waveform for audio and the notes for MIDI, and plays MIDI through the instrument the copy uses.

In any DAW

CLAP, VST3 and AU, plus a standalone app for working without a DAW and for Pro Tools. Windows, macOS and Linux.

Free, offline, no AI

No tier, no account, no telemetry, no network, no model. Classic signal processing, enforced by a build gate rather than promised.

The things most sites put at the bottom

A MIDI copy of a mix is a transcription

Finding notes in a finished mix is hard, and Flipcopy does it with classic signal processing rather than a model. It will miss some notes and hear some that are not there. It prints what it found, and says what it could not do.

Chords come back as a progression

A chord part is printed as the progression it follows, not the exact voicing that was played, and the page says so in so many words.

There are no downloads before 1.0.0

No beta on this page, no preview build, no early access. A copier that half-works is worse than one that is not there yet.

It never goes online

The plugin and the standalone app contain no networking code at all, and a build gate fails if any is added. A later version may add an update check that is off unless you switch it on, run by a separate program.
