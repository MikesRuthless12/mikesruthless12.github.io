What version 1.0 does

A live index of every disk

One index across your drives, kept current by each system's own change feed — the NTFS change journal on Windows, FSEvents on macOS, inotify and fanotify on Linux — so new, renamed and deleted files show up without a rescan. A drive you unplug stays searchable, and its results say which drive they are on.

File names, the way Everything finds them

Substrings, wildcards, regular expressions, AND, OR, NOT and grouping, with Everything's modifiers and spellings for size, date, extension, attributes and path, and seven match modes, from Match Case to Ignore Punctuation and matching Chinese, Japanese and Korean names by their reading.

The text inside files

Full-text search in PDFs, Word, Excel and PowerPoint files, plain text and Markdown, source code in 32 languages, JSON, CSV and YAML, mail, and inside zip, 7z and tar archives without unpacking them. A viewer steps through every hit in context.

Audio by how it sounds

Measured, not tagged: loudness in LUFS, true peak, silence, dynamic range, length, codec, sample rate and channels. Sort by loudness or length, and play a file in the preview without leaving the list.

What a file says about itself

Seventy-two properties read from file headers and searched like any other modifier: image size and camera data, video codec and duration, document author and page count, a program's architecture and signature, installer versions, shortcut targets, archive contents, fonts, mail headers and database tables. Any of them can be a column.

Names that are only close

The similarity lens finds names near what you typed — a typo, a version number, a different prefix — and a search that finds nothing offers the closest real name as a one-click correction.

Everything you do with a result

Open, reveal, Open with, copy the path, the name, the contents or the file itself, open a terminal there, and run commands you define. Space opens Quick Look, audio and video play in the preview, and the result count opens statistics for the whole set.

Rename, undo, tidy up

Rename a whole set of results with find and replace, regular expressions, counters and case changes, previewed first and refused if two names would collide. Undo reverses a rename, even after a restart. Find duplicates and empty folders straight from the index.

At home if you come from Everything

Everything's search syntax, quick filters and file lists, in and out, plus CSV, plain text, playlists and NDJSON. A strict mode checks that a query uses only what Everything understands.

A command line for scripts

The freally command speaks the same query language, prints JSON, NDJSON, CSV or NUL-separated paths, returns exit codes that mean something, and completes in bash, zsh, fish and PowerShell.

Portable, if you want it

Run it from a USB stick: the index, settings, bookmarks and logs stay in a Data folder beside the app, and nothing is registered with the computer it is plugged into.

Eighteen languages, light or dark

Menus, settings and every dialog switch language live, and Arabic lays out right to left. The app follows your system's light or dark theme, or keeps the one you choose.

Why it is built the way it is

It listens instead of rescanning

Every system already records the changes to its files. Sourcerer reads that record rather than walking your folders on a timer, so the index stays current without reading the disk again.

It reads only what a question needs

A file's properties are read the first time a search asks about it, from its header alone, and kept until the file changes. Nothing decodes a picture or opens a database's rows to answer how wide an image is.

It says what it cannot see

A folder that could not be read looks just like an empty one, so Sourcerer names the folders it skipped and why. A count that reached its limit is shown as a minimum, never as an exact number.

It is careful with your files

A rename is previewed and happens all at once or not at all, a delete goes to the Trash or Recycle Bin, and a command of your own runs as a program with arguments, never as a shell line, after asking you once.

It stays on your machine

No telemetry. The index lives on your own disk, and nothing about your files or your searches is sent anywhere. The update check only asks whether there is a newer version, and you can switch it off.

It respects what you already know

Everything's syntax, filters and file lists behave as they do there, checked by tests, so the habits of years carry over — to two more operating systems.

What 1.0 does not do

  • It reads properties from file headers only: it does not decode pictures, play video or render documents to find them, so a property a header does not carry cannot be searched.
  • On macOS and Linux the first index walks every folder, so on a large disk it takes minutes rather than seconds.
  • A portable copy does not update itself: replace its folder with a newer version.

There are no downloads before version 1.0, and none on this page.
