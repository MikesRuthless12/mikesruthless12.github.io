Your files, byte for byte. Copied. A desktop file copier for Windows, macOS and Linux, with checksum verification, resume after a crash, two-way sync, undo and its own file server. No account, no telemetry and no AI.

What it is

Copying a big folder with your system's own copy dialog tells you very little: no checksum, no say in what happens to files that already exist, and no way back when the power goes out halfway through.

Freally File Manager is a copier built to be trusted with that job. Drop files on its window, pick a destination, and it copies them through your system's fastest copy path. Switch on verification and it reads every copy back and checks it against the original's checksum.

Around the copier is everything you reach for afterwards: a history of every job with re-runs and undo, checksum tools, two-way sync and live mirroring, snapshots, a built-in file server and a command line for scripts.

What is in it

Byte-exact copies

Every file is copied byte for byte through your system's own fast paths, and cloned instantly on drives that support it. Pause, resume or cancel any job, and decide before it starts what happens when a file already exists.

Verified when you ask

Switch on verification and each copy is read back and checked against the original with one of eight checksums, from CRC32 and xxHash3 to SHA-256 and BLAKE3. A mismatch is reported, never hidden.

It survives a power cut

A journal records how far each copy got. After a crash or a reboot, the part already written is checked and the copy carries on from there instead of starting again.

Two-way sync

Keep two folders in step in both directions, or mirror one onto the other. A file changed on both sides is a conflict: both versions are kept and you choose.

History and undo

Every job is recorded. Run it again, retry only the files that failed, or undo the last copy or move: undone copies go to the Recycle Bin or Trash, never straight to deletion.

Check your files any time

Hash any file with eight checksums, make and check .sha256 or .sfv files, compare a folder with its copy months later, and export a signed report of what was copied.

Your own file server

Serve a folder to other computers over WebDAV, plain HTTP, an S3-compatible API or SFTP, read-only if you like, behind a password or a token.

Free, private, no AI

No account, no telemetry and no machine learning. Your files go only where you send them, and the daily update check can be switched off.

The things most sites put at the bottom

Verification is off until you switch it on

Checking a copy means reading it a second time, so it is a setting rather than the default. Choose a checksum in Settings → Transfer, and every copy after that is checked.

Two things 1.0 cannot do yet

It cannot securely shred files, and it cannot copy to cloud storage. Settings already has a place for both, but neither is wired up in version 1.0.0.

When it goes online

Copying between your own drives, verifying and deleting make no network requests. It goes online for what you set up, such as the file server or testing a cloud account, and to check for updates when it starts, at most once a day, which you can switch off in Settings → Updates.
